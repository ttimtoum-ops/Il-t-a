# UMBRA — Le Pacte des Abysses · v2.0.0

Version 2 introduit la progression permanente du Monarque, indépendante de la classe.

## Arbre du Monarque
- Couronne de puissance : +5% dégâts par rang (5 rangs)
- Trône indestructible : +4% PV max par rang (5 rangs)
- Légion renforcée : +7% dégâts des ombres par rang (5 rangs)
- Domination absolue : +10% domination gagnée par rang (5 rangs)
- Éveil prolongé : +1 seconde d'éveil par rang (5 rangs)

Les rangs sont achetés avec l'essence dans le Codex et sauvegardés.

Décompresser l'archive et remplacer les fichiers du dépôt par les fichiers à la racine, puis commit sur main.
